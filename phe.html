Overview

PHE is a secure manual cipher that uses a Lagged Fibonacci Generator to produce a high-entropy keystream. It uses three keys: Keys 1 and 2 create scrambled alphabets for a Tabula Recta, while Key 3 masks a unique random seed.

Step-by-Step Instructions

  1. Key Preparation: Clean Keys 1 and 2 (remove spaces/punctuation). Write them into a 25-column grid. Perform "Serpentine" lookups on a standard Tabula Recta (Down → Left/Right → Up) to generate two Compressed Keys.
  2. Header Customization: Use the Compressed Keys to create two unique scrambled alphabets. Place Alphabet 1 on the Left/Right sides and Alphabet 2 on the Top/Bottom of the Tabula Recta.
  3. Text Processing: Convert text to CAPS. Numbers → A-J, Q → K. Replace spaces with Q and periods with QQ.
  4. Keystream Generation (Row 2):
    • Encrypting: Write a Random Seed (length of Key 3) and your plaintext on Row 1. Write Key 3 on Row 2 below the seed. To fill the rest of Row 2, use the Lagged Fibonacci move: Look up the first available letter from Row 1 on the Top/Bottom, move until you find the next letter of the stream, then read the result from the Side alphabet.
    • Decrypting: Write the ciphertext on Row 1. Write Key 3 on Row 2 and use Key 3 and the first few letters of ciphertext to reverse-lookup the original Seed into Row 3. Then, use that seed to extend the keystream across Row 2 using the same lookup move as above.
  5. Final Operation (The Result):
    • To Encrypt: Look up the Row 1 letter on the Top/Bottom headers, move into the table to find the Row 2 letter, then read the result from the Side alphabets. Write this in Row 3.
    • To Decrypt: Look up the Row 1 letter on the Side alphabets, move into the table to find the Row 2 letter, then read the result from the Top/Bottom headers. Write this in Row 3.
Mental Map of Tabula Recta Moves (The "Hand Path"):

• 1. Seed Extraction (Start of Decryption Only):
  Look up [Row 1 Ciphertext] on Side → Find [Row 2 Key 3] Internally → Read result from Top/Bottom → Write into Row 3 (Seed)

• 2. Keystream Generation (Extending Row 2):
  Note: Use the Seed you just put in Row 3.
  Look up [Row 3 Seed/Keystream] on Top/Bottom → Find [Next Stream Letter] Internally → Read result from Side → Write into Row 2

• 3. Final Operation (The Result - Row 3):
  If Encrypting: Look up [Row 1 Plaintext] on Top/Bottom → Find [Row 2 Keystream] Internally → Read result from Side → Write into Row 3
  If Decrypting: Look up [Row 1 Ciphertext] on Side → Find [Row 2 Keystream] Internally → Read result from Top/Bottom → Write into Row 3
